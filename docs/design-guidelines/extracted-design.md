# Extracted design direction

Source asset: `public/labslot-logo.png` supplied by the user.

The automated Gemini extraction path was unavailable because no Gemini API key was configured. These guidelines were extracted by direct visual inspection.

## Visual language

- Deep laboratory teal: `#006b66` and `#004c49`.
- Warm ivory background: `#fff9ee` with pale amber atmosphere.
- Supporting mint: `#a8d8c8`.
- Alert orange: `#e7672f`.
- Large rounded geometry and thick instrument-like strokes.
- Calm clinical surface with an editorial console layout, not a generic card dashboard.

## Typography

- Display: Georgia for a human, archival laboratory tone.
- Interface: Trebuchet MS for compact labels and form controls.
- Uppercase micro-labels with generous tracking.

## Layout

- Header behaves like an instrument identity strip.
- Hero uses asymmetric text and a cropped logo specimen.
- Primary workflow is a horizontal phase rail plus one focused action workbench.
- On-chain readback remains visible as a separate evidence ledger.
- Responsive layout collapses into one column below 860px without nested scrolling.

## Interaction

- One primary write button for the selected phase.
- Disabled actions explain the exact contract gate.
- Transaction progress distinguishes signature, consensus, finality and readback.
- Success is shown only after authoritative state readback.
